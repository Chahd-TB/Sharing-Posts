# 🌐 Sharing Posts Website

A social media web application built with HTML, CSS, and JavaScript, connected to the Tarmeez Academy API.
The platform allows users to create real accounts, share posts, interact through comments, and manage their profiles — all in real time using internet-based API requests.

# 🧩 Overview

This project is a mini social network where users can:

Sign up, log in, and manage their profile.

Share posts with images and text.

View posts from other users.

Comment, edit, and delete their own posts.

It’s fully functional with real user authentication and connected to the Tarmeez Academy REST API.

# ✅ Implemented

🖼️ Post Management — create, edit, delete
